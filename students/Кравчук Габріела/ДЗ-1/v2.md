# Кравчук Габріела — ДЗ-1, v2 (15.11.2026, надіслано куратором у чаті, текст без змін; ДЗ-1 і ДЗ-2 разом)

Homework 1 -  Provide 3 examples of a Product, Project, Program, and Portfolio.

Example 1 - Ariport: 
PORTFOLIO: Reduce the average passenger waiting time at the airport by 25% by the end of 2028
PROGRAM: Make security checks faster and safer for passengers
PROJECTS: 
-Installing new and faster baggage scanners
- Connecting the scanners to the more accurate security system that helps detect dangerous items
- Testing the new security system and training airport staff to use it
PRODUCTS:
- New baggage scanners
- Integrated security system
- New security screening procedures

Example 2 - Public transport: 
PORTFOLIO: increase the number of people using public transport by 20% by the end of 2028
PROGRAM: Make public transport easier and more comfortable for people
PROJECTS: 
- Building new tram lines
- Building new tram stops along these lines, where necessary
- Installing electronic information boards at all tram stops
PRODUCTS:
- New tram lines
- New tram stops
- Electronic information boards

Example 3 - Language School: 
PORTFOLIO: Increase the number of students by 30% by the end of 2028 
PROGRAM: Start offering online language courses to reach students from different cities. PROJECTS: 
- Creating online language courses and preparing teaching materials
- Building an online learning platform where students can attend classes
- Creating an online booking and payment system for the courses
PRODUCTS:
- Online language course materials
- Online learning platform.
- Online booking and payment system.
