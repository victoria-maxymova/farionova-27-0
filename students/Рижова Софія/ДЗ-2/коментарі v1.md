# Рижова Софія — ДЗ-2, коментарі до v1 (коло 1, 12.11.2026)

Звірено з офіційним еталоном ДЗ 2. Повідомлення студентці — спільне по ДЗ 1 і ДЗ 2, у `ДЗ-1/коментарі v1.md`.

## Коментарі в документі (по порядку рядків таблиці)

1. **Executive Sponsor** — загальний коментар (до клітинки з етапами)
> Усі ролі на місці, супер 🙌 Зараз вони розподілені по фазах Inception / Development / Run. Спробуй, будь ласка, розкласти їх детальніше, по всіх 7 етапах: Conceptualize, Discover, Specify, Construct, Validate, Deliver, Run ✨
2. Salesman — без коментаря
3. Project Manager — без коментаря
4. **Program Manager** — коментар
> Етапи — так 💜 Невелика підказка щодо боку: Program Manager контролює головні етапи проєктів з боку команди, яка їх виконує 🌸
5. **Project Portfolio Manager** — коментар
> Як і Program Manager, він стежить за проєктами з боку команди виконавця. Поглянь, будь ласка, ще раз на бік ✨
6. **Product Manager** — коментар
> Замовник — так 💜 Підказка: з боку замовника він супроводжує проєкт на всіх етапах, ділячись баченням продукту, а з боку виконавця теж може долучатися під час розробки. Поглянь ще раз на етапи й бік 🌸
7. **Business Analyst** — коментар
> Невелика підказка: BA описує вимоги, зібрані від клієнта, і долучається вже тоді, коли починається розробка. Поглянь, будь ласка, ще раз на етапи й бік ✨
8. **System Analyst** — коментар
> Він теж працює з вимогами до системи саме під час розробки, з боку команди виконавця. Поглянь ще раз на етапи й бік 💜
9. **Subject-matter expert (SME)** — коментар
> Замовник — так 🙌 Підказка щодо етапів: експерт зазвичай допомагає команді від Discover аж до запуску продукту ✨
10. Architect — без коментаря
11. Development Team — без коментаря
12. Quality Assurance (QA) — без коментаря
13. Quality Control (QC) — без коментаря
14. Configuration Manager — без коментаря
15. Analyst — без коментаря
16. **Professional Service** — коментар
> Невелика підказка: ці фахівці контролюють якість аж до запуску в продакшн і найчастіше працюють на стороні замовника 🌸 І дрібничка: «Professional Services».
17. Support Team — без коментаря
18. **UI team** — коментар
> Development — так 💜 Підказка: дизайнери лишаються з проєктом до самого запуску, бо можуть дороблювати макети й стани елементів ✨
19. End User — без коментаря
20. **SEPG** — коментар
> Невелика підказка: SEPG допомагає команді з технічними питаннями та стандартами саме під час розробки. Поглянь, будь ласка, ще раз на етапи 🌸

## Висновок для куратора
- Ролі розподілені по 3 фазах замість 7 етапів — попросили розкласти.
- Бік: Program/Portfolio Manager → виконавець; Product Manager → обидва; BA і System Analyst → виконавець; Professional Services → замовник.
- Етапи: BA/SA — Development; SME — до запуску; UI team і Professional Services — до Run; SEPG — Development.
- Статус 🟠1.
