Homework 1

1. Салон краси

Продукт - послуга зачіски, манікюру, покраски і тд
Проект  - запуск нового напрямку роботи - ламінування вій, рекламний проект по просуванню цього напрямку, проект по створенню навчання для майстрів
Програма - проекти 1го напрямку, наприклад, манікюру : Рекламні проекти по просуванню цього напрямку, проекти по підвищенню кваліфікації майстрів, проекти по набору і навчанню майстрів, закупки обладнання і матеріалів
Портфель - Розвиток різних локацій салонів в місті

2. клуб бойових напрямків

Продукт - Тренування з айкідо, боксу, стретчингу
Проект - підготовка програми тренувань та навчання тренерів цим програмам, організація атестацій( персонал, рекламна продукція, закупки, пошуку приміщення)
Програма - проекти по окремим напрямкам (акідо,бокс і тд)
Портфель - розвиток по різним містам

3. прокат суконь

Продукт - сукні, які надаються в оренду, аксесуари, послуга візажу
Проект - проект організації закупки,проект організації прийому і хімчистки, рекламний проект по просуванню
Програма -  проект організації закупки, проект організації прийому і хімчистки,проект організації закупки по різним локаціям.
Портфель - розвиток по різним містам
