# Станіславчук Світлана — ДЗ-1, v1 (15.11.2026, надіслано куратором у чаті, текст без змін)

Три приклади продукту, проєкту, програми та портфеля:

Приклад  #1:
FMCG-компанія

Продукт - мобільний застосунок для торгових представників і власників роздрібних точок.
Проєкт - впровадження модуля автоматичних знижок у мобільному застосунку для торгових представників.
Програма - «Цифрова трансформація дистрибуції» 
Портфель-  «Стратегія 2026–2028» компанії (Програма - Цифрова трансформація дистрибуції,
Програма - Запуск лінійки безцукрових напоїв, Проєкт - Перехід на ESG-звітність, Проєкт - Модернізація лінії розливу на завод).

Приклад  #2:
СТО
Продукт: мобільний застосунок для запису клієнтів на обслуговування.
Проєкт: додавання онлайн-оплати в застосунок.
Програма: застосунок для клієнтів, CRM для менеджерів, система обліку запчастин
Портфель: програма мобільний застосунок для клієнтів, проєкт відкриття нової станції, проєкт закупівлі діагностичного обладнання, операційна діяльність: підтримка існуючих СТО.

Приклад  #3:
Miltech 
Продукт: система розвідувальних БпЛА  (дрон + наземна станція керування + ПЗ).
Проєкт: розробка нової версії прошивки з захистом від РЕБ.
Програма: розробка дрона нового покоління, система захищеного зв'язку, модуль розпізнавання цілей на базі ШІ, навчання операторів.
Портфель: «Розвиток оборонних рішень 2026–2028» - програма розробка дрона нового покоління, проєкт розширення виробничої лінії, проєкт сертифікації за стандартами НАТО, операційна діяльність: сервіс і ремонт поставлених систем.
