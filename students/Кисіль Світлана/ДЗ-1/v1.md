# Кисіль Світлана — ДЗ-1, v1 (17.11.2026, надіслано куратором у чаті, текст без змін)

1. Продукт

1. Мобільний застосунок для замовлення їжі.(Bolt food)
2. Pos система для ресторану (Syrve)
3. Цифровий продукт для перегляду фільмів і серіалів (Netflix)

2. Проєкт 

1. Розробка нового мобільного застосунку для доставки їжі.
2. Відкриття нового ресторану.
3. Створення та запуск нового сайту для магазину.

3. Програма 

1. Програма розвитку міської інфраструктури — включає проєкти ремонту доріг, модернізації громадського транспорту та облаштування парків, дитячих майданчиків та пішохідних зон.
2. Програма відкриття мережі ресторанів у різних містах, яка включає проєкти пошуку приміщень, ремонту, закупівлі обладнання та запуску закладів.
3. Програма організації весілля — включає проєкти вибору локації, оформлення, замовлення кейтерингу та організації музичного супровіду.

4. Портфель 

1. Портфель туристичної компанії — запуск нових туристичних напрямків, створення сайту, відкриття офісів та розвиток реклами.
2. Портфель ресторанної компанії: відкриття нових закладів, оновлення меню, впровадження системи лояльності та автоматизація обліку.
3. Портфель фітнес-клубу — відкриття нового залу, закупівля тренажерів та інвентаря, запуск групових та індивідуальних занять, створення мобільного застосунку або сайту.
