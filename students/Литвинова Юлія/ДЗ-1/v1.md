# Литвинова Юлія — ДЗ-1, v1 (18.11.2026, текст надіслано куратором без підпису)

_Авторство визначено за темою (школа айкідо - Юлія адміністратор у школі айкідо для дітей); підтверджено куратором._

Домашне завдання №1 

1. Приклад:

Продукт - додаток на телефон для учнів школи з айкідо.
Проект - створення розділу "домашні завдання з розпізнаванням рухів через ШІ"
Програма - розробка відео вправ, прийомів та рухів для ДЗ, та інтегрування ШІ для розпізнавання правильності виконання завдань.
Портфель - створення розділу ДЗ для школи айкідо та художньої гімнастики.

2. Приклад:

Продукт - осіння фотосессія для 9 класу.
Проект - створення зимової та весняної фотосессій.
Програма - розробка та друк готових альбомів для 9 класу на основі фотосессій.
Портфель - використання шаблонів для створення альбомів для 9 та 4 класі.

3. Приклад:

Продукт - лего роботи для дітей на основі Lego Spike.
Проект - створення інструкцій по складанню та програмуванню роботів.
Програма - розробка роботів під кожну біблійну історію (курс на 12 місяців).
Портфель - розробка курсу для Європи та України.
