# Мороз Софія — ДЗ-2, v2 (виправлена версія після кола 1; надіслано куратором 13.11.2026, текст без змін)

| Роль (з якого боку виступає) | Життєвий цикл проекту (SDLC) |
|---|---|
| Executive Sponsor - спонсор, людина, яка насичує проект фінансами - замовник | Conceptualize, discover,specify, construct, validate, deliver |
| Salesman - продажник, що шукає замовників - виконавець | Conceptualize, discover,specify |
| Project Manager - відповідальна особа за проект- виконавець/замовник | Усі етапи(в ідеалі) або ж починаючи з Specify-Run |
| Program Manager - менеджер, керуючий групою проектів-виконавець | Усі етапи |
| Project Portfolio Manager - керуючий портфелем проектом - виконавець | Усі етапи |
| Product Manager - знає ринок, пропонує замовнику потрібний функціонал та впроваджує його - виконавець/замовник | Усі етапи |
| Business Analyst - визначає написання вимог - виконавець | Construct,validate, deliver |
| System Analyst - визначає написання вимог до системи - виконавець | Specify, construct, validate, deliver |
| Subject-matter expert (SME) - людина, яка знається на конкретній сфері - замовник | Discover, specify, construct, validate, deliver |
| Architect - спеціаліст з архітектури, вибору інструментів, технологій і т.д. - виконавець | Construct, validate, Deliver |
| Development Team - команда розробників (програмують), тім-лідерів ( програмують та проводять рев'ю коду інших розробників) - виконавці | Construct, validate, deliver |
| Quality Assurance (QA) - вибирають процеси та інструменти для тестування, щоб запобігти помилкам - виконавці | Specify, construct, validate, deliver |
| Quality Control (QC) - стежать за процесом контролю якості (тестують, виявляють помилки, контролюють їх усунення), складають кейси - виконавці | Construct,Validate, deliver |
| Configuration Manager - налаштовує оточення, складає збірки - виконавець | Construct, validate, deliver |
| Analyst - аналітик, перевіряє коректність збору метрик, підбиває результат про успішність проекту/продукту - замовник/виконавець | Discover, Construct, Validate, Deliver |
| Professional Services - людина чи група людей, які тестують продукт поза командою - замовник | Construct,Validate, Deliver, Run |
| Support Team - команда підтримки, супроводу продукту - виконавеці | Deliver, run |
| UI team - дизайнери, верстальники, юзабілісти - виконавці | Construct, Validate, Deliver, Run |
| End User - кінцевий користувач - замовник | Run |
| Software Engineering Process Group (SEPG) - група людей, які займаються аналізом процесів, їх змін -виконавці | Construct, Validate, Deliver |
