# Мороз Софія — ДЗ-2, v1 (надіслано куратором 12.11.2026, текст без змін)

| Роль (з якого боку виступає) | Життєвий цикл проекту (SDLC) |
|---|---|
| Executive Sponsor - спонсор, людина, яка насичує проект фінансами - замовник | Inception (Conceptualize, discover,specify) |
| Salesman - продажник, що шукає замовників - виконавець | Conceptualize, discover,specify |
| Project Manager - відповідальна особа за проект- виконавець | Усі етапи(в ідеалі) або ж починаючи з Specify-Run |
| Program Manager - менеджер, керуючий групою проектів- замовник/виконавець | Усі етапи |
| Project Portfolio Manager - керуючий портфелем проектом - виконавець | Conceptualize, |
| Product Manager - знає ринок, пропонує замовнику потрібний функціонал та впроваджує його - виконавець | Усе, крім construct |
| Business Analyst - визначає написання вимог - замовник/виконавець | Discover, specify, validate |
| System Analyst - визначає написання вимог до системи - виконавець | Specify, construct, validate |
| Subject-matter expert (SME) - людина, яка знається на конкретній сфері - замовник | Discover, specify, validate |
| Architect - спеціаліст з архітектури, вибору інструментів, технологій і т.д. - виконавець | Construct, validate |
| Development Team - команда розробників (програмують), тім-лідерів ( програмують та проводять рев'ю коду інших розробників) - виконавці | Construct, validate, deliver |
| Quality Assurance (QA) - вибирають процеси та інструменти для тестування, щоб запобігти помилкам - виконавці | Specify, construct, validate, deliver |
| Quality Control (QC) - стежать за процесом контролю якості (тестують, виявляють помилки, контролюють їх усунення), складають кейси - виконавці | Validate, deliver |
| Configuration Manager - налаштовує оточення, складає збірки - виконавець | Construct, validate, deliver |
| Analyst - аналітик, перевіряє коректність збору метрик, підбиває результат про успішність проекту/продукту - замовник/виконавець | Discover, validate |
| Professional Services - людина чи група людей, які тестують продукт поза командою - виконавці | Validate, deliver |
| Support Team - команда підтримки, супроводу продукту - виконавеці | Deliver, run |
| UI team - дизайнери, верстальники, юзабілісти - виконавці | Discover, dpecify, construct, validate |
| End User - кінцевий користувач - виконавець | Deliver, run |
| Software Engineering Process Group (SEPG) - група людей, які займаються аналізом процесів, їх змін -виконавці | (етапи не вказані) |
