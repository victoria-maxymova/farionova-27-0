**Inception (початок)**
| Підетап | Ролі |
|---|---|
| Conceptualize (ідея, обґрунтування) | Executive Sponsor, Salesman, Product Manager, Portfolio Manager, Program Manager, Project Manager (призначається, планує) |
| Discover (дослідження потреб) | Business Analyst, Product Manager, Project Manager, SME, System Analyst, Executive Sponsor |
| Specify (вимоги, специфікація) | Business Analyst, System Analyst, Architect, SME, UI team (прототипи), QA (стратегія тестування), Project Manager, Product Manager, Executive Sponsor |

**Development (розробка)**
| Підетап | Ролі |
|---|---|
| Construct (створення продукту) | Development Team, Architect, UI team, Configuration Manager (збірки, оточення), Business Analyst, System Analyst (уточнення вимог), QA, Project Manager, Product Manager |
| Validate (перевірка якості) | QC, QA, Business Analyst, SME, Analyst (метрики якості), Professional Services (тестування поза командою), End User (приймальне тестування), Project Manager, Product Manager |
| Deliver (випуск, передача) | Configuration Manager (фінальна збірка), Development Team, Project Manager, Support Team (приймає продукт), Executive Sponsor (підтвердження результату) |

**Run (експлуатація)**
Support Team, End User, Analyst (метрики успішності продукту), Professional Services, Product Manager (розвиток продукту), Executive Sponsor (оцінка результату), Project Manager.

**Ролі, які присутні на всіх етапах**
Project Manager веде проєкт від початку до кінця.
Program Manager і Project Portfolio Manager стежать за проєктом у контексті групи проєктів і портфеля, на всіх етапах, але найбільше на Inception.
SEPG аналізує процеси та пропонує зміни протягом усього життєвого циклу.
Architect найактивніший на Specify та Construct, але може залучатися й пізніше.
