## Відповіді на питання студентки в коментарях (до коментарів кола 1)
- **Salesman** («Він на всіх етапах теж, вірно?»):
> Не зовсім 😊 Продажник працює лише на старті, протягом усього Inception: знаходить клієнта, домовляється й допомагає сформувати вимоги. А щойно починається розробка, він передає проєкт команді, і далі його робота завершується 🌸 Тож у тебе вже було майже правильно, лишалось тільки прибрати етап після Specify ✨
- **Portfolio Manager** («Виконавець?»):
> Так, саме так ✅ Portfolio Manager працює з боку виконавця, тож знак питання можна сміливо прибрати 💜

## Висновок для куратора
- Враховано: Program Manager додано; Executive Sponsor (+ Construct), Portfolio Manager (усі етапи, виконавець), SME/Architect/BA (+ Deliver), Analyst (+ Deliver), Configuration Manager (Run прибрано), Prof. Services (+ Construct, замовник), Support Team (Specify прибрано), UI team (+ Deliver, Run), End User (Discover і Validate прибрано), SEPG (лише Development) ✅
- Нові неточності (перестаралась): Salesman — тепер усі етапи (треба лише Inception); System Analyst — тепер усі етапи (зайві Conceptualize і Run); Architect і BA — додано Run.
- Program Manager — «обидва боки» (за еталоном виконавець).
- Знаки «?» біля Portfolio Manager (виконавець) і Prof. Services (замовник) — відповіді правильні.
- End User: лишився Conceptualize; Deliver — новий (як A/B-тест у Литвин, не коментуємо).
- BA на Run — не коментуємо (правило про BA), або разом з Architect — рішення куратора.
- Статус 🟠2.
