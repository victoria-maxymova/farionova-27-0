**Приклад 1**
- Продукт: Сайт танцювальної студії
- Проєкт: 1 Розробка дизайну сайту. 2 Створення блоку з розкладом та прайсомю 3 розробка сторінок з описами танцювальних напрямків та інформацією про тренерів студії.
- Програма: Програма цифрової трансформації танцювальної студії. Мета: автоматизація взаємодії з клієнтами, покращення сервіса та залучення нових клієнтів за допомогою онлайн-запису і подальшої оплати безпосередньо на самому сайті.Також клієнт зможе створити свій особистий кабінет, в якому буде відслідкувати свій прогрес, кількість пройдений занять та бачити бонуси по програмі лояльності.
- Портфель: Сукупність усіх програм і продуктів для цифрового розвитку студії. Сайт студії,  мобільний застосунок студії, портал для навчання тренерів. Стратегічна ціль: збільшити показник конверсії студії з 0.7 до 1.1 до кінця першого кварталу 2027 року за рахунок онлайн-запису.

**Приклад 2**
- Продукт: Програма для оплати комунальних послуг
- Проєкт: Розробка блоку для оплати газу/ електропостачання/ води/ вивозу сміття. Розробка особистого кабінету абонента. Розробка автоматичного розрахунку платежів. Розробка блоку автоматичної онлайн синхронізації показників між абонентом та постачальником послуг.
- Програма: Програма цифровізації та автоматизації передавання показників. Мета - зробити максимально зручну і зрозумілу програму для зручності абонентів будь якого віку. Та створити централізований сервіс, який буде містити повну інформацію по всім послугам, включая історію оплат, історію показників і тарифів, які будуть доступні в особистому кабінеті абонента.
- Портфель: Цифрова трансформація команульного підприємства.В яку можуть входити: програма по автоматизації комунальних послуг, мобільний застосунок для абонентів, мобільний застосунок для комунальних підприємств, база CMR . Стратегічна ціль: збільшити частку абонентів, які будуть вносити і оплачувати показники онлайн без задіяння банків та втрати власного часу в чергах при оплаті кожної послуги окремо, на 40% в порівнянні з минулим роком.

**Приклад 3**
- Продукт: Сайт для бронювання квитків на концерт в Україні
- Проєкт: 1.Розробка дизайну та інтерфейсу. 2. Розробка прийому платіжів. 3. Розробка особистого кабінету глядача. 4. Розробка особистого кабінету для організаторів концертів. 5. Розробка схем концертних залів в різних містах України, де будуть проводитись концерти. 5.Розробка сповіщення для глядача. 6. Розробка механізму повернення коштів.
- Програма: Програма цифрової автоматизації бронювання квитків
- Портфель: Стратегічний розвиток компанії по продажу квитків може включати в себе: 1. Сайт для бронювання квитків в Україні. 2. Мобільний застосунок для Iphone. 3. Мобільний застосунок для Android. 4. CRM система. 5. Міжнародний сайт для бронювання квитків. Стратегічна ціль: збільшити кількість проданих квитків за допомогою залучення сайту, застосунку та міжнародного сайта на 60% до кінця 2027 року.
