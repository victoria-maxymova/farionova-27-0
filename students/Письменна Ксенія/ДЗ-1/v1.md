# Письменна Ксенія — ДЗ-1, v1 (надіслано куратором 13.11.2026, текст без змін)

Продукт 1 - Сайт зоомагазину

Проєкти:

1.  Додати кошик і оплату карткою
2.  Зробити пошук по сайту
3.  Зробити мобільну версію сайту

Програми:

1. Запуск доставки (підключення Нової пошти, розрахунок вартості, відстеження посилки)
2. Залучення клієнтів (реклама в Instagram, знижка на перше замовлення)

Портфель:

1. Розвиток сайту зоомагазину (програма доставки, проєкт кошика й оплати, проєкт оновлення дизайну)



Продукт 2 - Додаток для доставки їжі

Проєкти:

1. Додати оплату карткою
2. Зробити відстеження замовлення на карті
3. Додати сповіщення про статус замовлення

Програми:

1. Запуск доставки (екран замовлення, додаток для кур’єрів, кабінет для ресторанів)
2. Програма лояльності (бонуси, промокоди, знижки для постійних клієнтів)

Портфелі:

1. Розвиток сервісу доставки в місті (програма запуску доставки, проєкт оплати карткою, проєкт відстеження замовлення)
2. Утримання клієнтів (програма лояльності, проєкт сповіщень про акції)


Продукт 3 - Додаток для фітнес-клубу

Проєкти:
1. Додати розклад занять з онлайн-записом
2. Додати оплату абонементів у додатку
3. Зробити профілі тренерів
Програми:

1. Дитячий напрямок (дитячі абонементи, кабінет для батьків, профілі дитячих тренерів)
2. Онлайн-тренування (відеоуроки, прямі ефіри, особисті плани)

Портфелі:

1. Розвиток фітнес-клубу онлайн (дитяча програма, проєкт онлайн-запису, проєкт оплати абонементів)
2. Розширення аудиторії (програма онлайн-тренувань, проєкт профілів тренерів, проєкт реклами в додатку)
