# Лугова Аміна — ДЗ-1, v2 (14.11.2026, надіслано куратором у чаті, текст без змін)

3 Приклади: продукту, проекту, програми та портфелю.

1. Компанія пивних барів

Продукт: Пиво, закуски, сервіс,  і вся інша продукція, яку продає бар.
Проект: Проект по виготовленню власного пива, розробка меню, найм співробітників, запуск турнірів з дартсу.
Програма: Сукупність проектів об’єднаних для розвитку нової філії бару - проекти по виготовленню продукції;  проект по маркетингу, щоб люди дізнавалися про бар та були зацікавленні прийти; проект по дизайну бару; проект по фінансовій економіці бару, впровадження турнірів з дарсу. 
Портфель: Вивести нову філію на дохід в 200000 тисяч євро на рік до березня 2028 ( використовувати програму розвитку нової філії, проект по виготовленню власного пива та розробки меню також проект по запуску турнір з дартсу). 

2. Бренд косметики для догляду за шкірою 

Продукт: доглядова косметика ( крема, тонери, спф..)
Проект: розробка сайту, рекламна компанія нового продукту( крема з ретинолом) , розробка нової формули для крема з ретинолом. 
Програма:  розвиток цифрової сторони бренду   : створення мобільного додатку; впровадження штучного інтелекту; опис складу, особлива увага на діючих компонентах; індивідуальні поради за типом шкіри та її потребами; інтеграція онлайн- магазину; 
(додаток бренду з  впровадженим штучним інтелектом  який підбере індивідуальний догляд  під конкретний тип шкіри та її потреби, з детальним описом діючих компонентів в складі продукції ) . Вихід на ринок Австрії ( розробка нового крему з ретинолом, рекламна компанія продукції, новий сайт для клієнтів Австрії, інтеграція онлайн магазину.)
Портфель: Збільшити продажі  нового продукту на 40% до початку 2028 року( програма виходу на ринок Австрії, програма цифровізація бренду, проект розробки нового крему з ретинолом, реклама, співпраця з блогерами).

3. Фітнес компанія

Продукт: абонемент в зал, групові тренування, індивідуальні заняття з тренером.
Проект: закупка нового обладнання для групових тренувань; розробка нової системи тренувань для жінок в декреті; розробка програми лояльності для постійних клієнтів.
Розробка онлайн додатку з тренуваннями. 
Програма: відкриття нової точок в сусідньому місті, що буде включати в себе різні проекти по найму персоналу, закупки обладнання, пошук приміщення, рекламну компанію. Запуск нової системи тренувань для жінок в декреті, це буде сукупність проектів таких як: розробка  цієї системи, маркетинг для залучення нових клієнтів, закупка спеціального обладнання, дизайн відведеного приміщення,  залучення цієї систему до онлайн додатку. 
Портфель: Відкрити спортзали в кожному місті по всій країні до 2028 роки ( використовувати програму відкриття нових точок з наймом персоналу, закупкою обладнання, вибір локації та рекламу).  Збільшити прибуток від кожного залу на 10% до кінця 2029 року ( в над цим будуть працювати проекти  впровадження нових систем тренувань для жінок в декреті,  програма лояльності для постійних клієнтів та реклама компанія).
