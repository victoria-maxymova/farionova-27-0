3 Приклади: продукту, проекту, програми та портфелю.

1. Компанія пивних барів


Продукт: Пиво, закуски, сервіс,  і вся інша продукція, яку продає бар.
Проект: Проект по виготовленню власного пива, розробка меню, найм співробітників. 
Програма: Сукупність проектів об’єднаних для розвитку нової філії бару - проекти по виготовленню продукції;  проект по маркетингу, щоб люди дізнавалися про бар та були зацікавленні прийти; проект по дизайну бару; проект по фінансовій економіці бару, аби вийти в прибуток. 
Портфель: Стратегічний план по створення турнірів з дартсу в кожній філії аби збільшити причини прийти до бару та привабити нових клієнтів. 

2. Бренд косметики для догляду за шкірою 


          Продукт: доглядова косметика ( крема, тонери, спф..)
Проект: розробка сайту, рекламна компанія нового продукту( крема з ретинолом) , розробка нової формули для крема з ретинолом. 
Програма:  розвиток цифрової сторони бренду   : створення мобільного додатку; впровадження штучного інтелекту; опис складу, особлива увага на діючих компонентах; індивідуальні поради за типом шкіри та її потребами; інтеграція онлайн- магазину; 
(додаток бренду з  впровадженим штучним інтелектом  який підбере індивідуальний догляд  під конкретний тип шкіри та її потреби, з детальним описом діючих компонентів в складі продукції ) . 
Портфель: Вихід на ринок Австрії ( розробка нової лінійки, рекламна компанія продукції, новий сайт для клієнтів Австрії..)
Стратегічний розвиток бренду, в портфель будуть входити як і програми так і проекти щоб розвивати бренд, вивести  його на новий закордонний ринок. Вибирати пріоритетні шляхи розвитку та стратегічно  інвестувати в перспективні програми чи проекту. 



3. Фітнес компанія


Продукт: абонемент в зал, групові тренування, індивідуальні заняття з тренером.
Проект: закупка нового обладнання для групових тренувань; розробка нової системи тренувань для жінок в декреті; розробка програми лояльності для постійних клієнтів.
Розробка онлайн додатку з тренуваннями. 
Програма: відкриття нової точок в сусідньому місті, що буде включати в себе різні проекти по найму персоналу, закупки обладнання, пошук приміщення, рекламну компанію. Запуск нової системи тренувань для жінок в декреті, це буде сукупність проектів таких як: розробка  цієї системи, маркетинг для залучення нових клієнтів, закупка спеціального обладнання, дизайн відведеного приміщення,  залучення цієї систему до онлайн додатку. 
Портфель: Сукупність програм та проєктів для розширення сітки залів по цілій країні.
