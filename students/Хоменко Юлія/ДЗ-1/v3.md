# Хоменко Юлія — ДЗ-1, v3 (виправлена версія після кола 2)

_Текст роботи без змін, надіслано куратором 12.11.2026._

1. Освітня онлайн платформа для шкіл

Продукти:

* онлайн платформа для вчителів та учнів
* мобільний застосунок

Проекти:

* розробка нового функціоналу для додаткових гуртків
* створення відеоуроків для користувачів (про користування платформою)
* створення реклами для залучення нових шкіл
* проведення презентації освітньої платформи для шкіл у місті Київ.

Програма:

1. Програма з метою розвитку освітньої платформи шляхом покращення користувацького досвіду. 

Об’єднує в собі проекти з розробки нового функціоналу та створення уроків для користувачів.

2. Програма з метою залучення нових користувачів. 

Об’єднує в собі проекти зі створення та запуску рекламної компанії та проведення презентації для нових шкіл.

Портфель:
Стратегічна ціль портфелю: зайняти 20% ринку в Україні за 5 років.
Портфель включає в себе: 

* програму розвитку продукту та покращення користувацького досвіду.
* програма залучення нових користувачів.


2. Студія краси 

Продукти:
Послуги оформлення брів, ламінування вій, манікюр, педикюр.
Проекти:
- створення бази постійних клієнтів 
- створення програми лояльності для клієнтів (для нарахування бонусів та подарунків до замовлення)
- впровадження нової послуги - масажу
- запуск таргетованої реклами на нову послугу масажу
- декорування студії до новорічних свят
- підняття цін на послуги на 10% 
Програма:

1. Програма розвитку сервісу з метою утримання клієнтів.

Включає в себе проекти зі створення бази постійних клієнтів та програми лояльності для нарахування бонусів та подарунків.

2. Програма залучення нових клієнтів.

Включає в себе проект запуску нової послуги та подальшу рекламу на неї.
Портфель:
Стратегічна ціль портфелю: збільшити річний дохід студії на 30% до кінця 2028 року.
Портфель включає в себе: 

* програму утримання клієнтів
* програму залучення нових клієнтів
* проект перегляду і підняття цін
* проект декорування студії



3. Компанія з виробництва доглядової косметики.

Продукти:

* тонік для обличчя
* зволожуючий крем
* гель для вмивання
* сироватка з кислотами

Проекти:

* покращення формули крему
* створити промокод для наявних клієнтів на знижку 10%
* тестування новоствореної лінійки для вікової шкіри
* розробка дизайну пакування продуктів для вікової шкіри
* фотозйомка нової продукції для майбутньої реклами
* вихід на новий торгівельний майданчик

Програма:

1. Програма з метою підвищення лояльності клієнтів.

Включає в себе удосконалення застарілої формули крему, а також створення промокоду для постійних клієнтів.

2. Програма з розширення цільової аудиторії через запуск нової лінійки для вікової шкіри.

Включає в себе проекти в такій послідовності: тестування нової лінійки - розробка дизайну пакування - фотозйомка.

Портфель:

Стратегічна ціль: збільшити продажі компанії на 20% протягом 2-х років.
Портфель включає в себе:

* програму підвищення лояльності клієнтів
* програму розширення цільової аудиторії
* проект виходу на новий торгівельний майданчик
