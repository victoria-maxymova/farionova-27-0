# ДЗ 2 — Життєвий цикл проєкту і ролі в SDLC (Блок 2)

## Умова (зі слів куратора)
1. **На яких етапах бере участь кожна роль?** Розподілити всі ролі по етапах SDLC: Conceptualize, Discover, Specify, Construct, Validate, Deliver, Run. Кожна роль — під тими етапами, де вона залучена й працює.
2. **З якого боку виступає кожна роль?** Замовник / виконавець / обидва боки.

## Коротко для перевірки (моє зведення з офіційної відповіді)
- **Inception:** Executive Sponsor (замовник; + Development), Salesman (виконавець, весь Inception), SME (від Discover до запуску).
- **Усі етапи:** Project Manager (обов'язково й Run; обидві сторони), Program і Portfolio Manager (виконавець), Product Manager (замовник — усі фази; виконавець — лише Development).
- **Весь Development:** BA (лише виконавець; раніше — виняток), System Analyst (лише виконавець), Architect (виконавець; може й на початку), Dev Team, QA, QC, Configuration Manager, Analyst, SEPG (виконавець).
- **Development → Run:** Professional Services (частіше замовник), UI team.
- **Кінець Development + Run:** Support Team (виконавець; може бути й замовник як приймаюча сторона).
- **Лише Run:** End User — третя сторона (або замовник).
- Етапи всередині Development: Construct, Validate, Deliver.
